## 1. Main chip (ring: nRF54LM20A, `design/bom.csv` line 2): development kit, debugger, current measurement

**Kit: nRF54LM20 DK, maker Nordic Semiconductor, order code `NRF54LM20-DK`** (Digi-Key part 1490-NRF54LM20-DK-ND) [B1, F on Digi-Key 2026-11-10]. Nordic's DK page prints no order code [B1].

- The kit as sold carries the nRF54LM20B [B1, F]. **The A chip's rules on that kit (new in B2):** the Zephyr documentation of the board says "The nrf54lm20dk/nrf54lm20a board is a modified version of the nRF54LM20 DK that enforces the limitations imposed by the nRF54LM20A IC ... Since Nordic does not offer a development kit for the nRF54LM20A, you can use this board to develop for this IC while using the nRF54LM20 Development Kit (PCA10184)" [F, `https://docs.zephyrproject.org/latest/boards/nordic/nrf54lm20dk/doc/index.html`, saved text `design/bench/sources/zephyr_nrf54lm20dk_board.txt`, page last source update 2026-10-08]. The bench therefore builds for board target `nrf54lm20dk/nrf54lm20a/cpuapp`. This closes the "no kit carries the A die" gap of B1 as far as software can; the silicon stays the B die (plan D4).
- Pin map of the headers [F, new in B2]: DK schematic revision 0.5.4, sheet 8, saved as `design/bench/sources/dk_sch_p8_P1P2-08.png` and `dk_sch_p8_P17top-08.png`. Headers P1 to P5 are 2x10: pins 1, 2, 19, 20 are VDD:IO; P1 pin n = P0.(n-3) (P0.00 to P0.09); P2 pin n = P1.(n-3) (P1.00 to P1.15); P3 pin n = P1.(n+13) (P1.16 to P1.31); P4 pin n = P2.(n-3) (the nets are named P2.00_A to P2.10); P5 pin n = P3.(n-3) (P3.00 to P3.12). P17 (2x13) pin 1 VDD, pin 2 GND, and named pins A0 to F1, C4, G0, H0 to H5 with their chip pins. The user guide's own pin table is still not read (below).
- Pins the DK shares with its own parts [F, DK schematic sheet 2 text and sheet 4 image; Zephyr devicetree `design/bench/sources/zephyr_nrf54lm20dk_common.dtsi` and `zephyr_nrf54lm20dk_a_b_pinctrl.dtsi`]: push button 0 on P1.26, button 1 on P1.09, button 2 on P1.08, button 3 on P0.05; LEDs on P1.22, P1.25, P1.27, P1.28; uart20 on P1.16 to P1.19; uart30 on P0.06 to P0.09 (reaching the debugger through analog switches, sheet 4); the on-board QSPI flash on P2.00 to P2.05.
- Supply: VDD:nRF = VDD:IO = 1.8 to 3.6 V from the DK's own nPM1300; its start-up value is 1.8 V ("Startup VOUT1: 47k -> 1.8V", `design/bench/sources/dk_sch_p6-06.png`, sheet 6) [F]. "DK requires power from USB connector" in the default configuration; a manual override powers the chip through header P14 (sheet 4 note: "R43, R51 mounted: Analog switches are powered from P14") [F]. The two USB-C connectors: nRF USB (J3) and Debugger USB (J4), sheet 8 [F].
- Current measurement: P14 (1x3) and JP1 "Shunt 2.54mm" in the block "Current Measurement", sheet 6 [F]. Nordic's set-up page: "Remove the jumper from the P14 header" and "replace the measurement devices on P14 with the jumper" [B1, F, quoted].
- On-board debugger: SEGGER J-Link OB [B1, F].
- Caveat [B1, S]: a DevZone user read 89 uA on an nRF54LM20A DK against a 4 uA datasheet figure; no confirmed answer found.
- Price: **US$45.00** (quantity 1), Digi-Key US, 321 in stock, lead time 19 weeks, as read 2026-11-10 [B1, F]. Not read again in B2: Digi-Key answers curl with HTTP 403.
- Not read: the DK user guide v0.3.4 (a browser-check page, `design/datasheets/bench_nrf54lm20-dk-hw-ug-v0.3.4.pdf`) and the same guide through `https://docs.nordicsemi.com/bundle/ug_nrf54lm20_dk/...` (HTTP 403, `design/bench/sources/nordic_dk_connector_if.html`).

**Power Profiler Kit II, maker Nordic Semiconductor, order code `nRF-PPK2`** [B1, F: "Ordering code: nRF-PPK2" on `https://www.nordicsemi.com/startppk2`]. Range 200 nA to 1 A; supports all Nordic DKs [B1, F]. Price **US$107.30**, Digi-Key US part 1490-NRF-PPK2-ND, 1,608 in stock, lead 16 weeks, 2026-11-10 [B1, F]. Header names of the PPK2 are not read.

## 2. Power chip (ring: nPM1304-CAAA-R7, `design/bom.csv` line 3): nPM1304 EK

**Kit: nPM1304 EK, maker Nordic Semiconductor, order code `nPM1304-EK`.**

- Order code [F]: Nordic's nPM1304 Product Specification v1.0, "Table 50: nPM1304 order codes", page 168: "nPM1304-EK  Evaluation kit" (saved `design/datasheets/npm1304_datasheet_v1_0.pdf` and its text copy; also `design/architecture.md` line 644 and `design/ecad/motor-drive/motor-drive.md` section 2.9, which names the same kit for the motor test).
- Existence as a product [F]: the specification line "The nPM1304 Evaluation Kit provides simple evaluation and code-free configuration of nPM1304" (same text copy); Zephyr ships a shield `npm1304_ek` for it, "nPM1304 EK", with a 4 mA default charge current and PMIC buttons (saved `design/bench/sources/zephyr_npm1304_ek_doc.txt`, `zephyr_npm1304_ek_overlay.txt`, read 2026-11-11 UTC per the log); Nordic's own product line "The new nPM1304 Evaluation Kit is now available for order through Nordic's distribution partners" is quoted in `design/parts/research-npm1304.md` line 73 [F, saved file].
- Zephyr's page says the EK "is not a direct fit into an Arduino connector" and that its I2C lines must be connected to the board's I2C bus [F]. No header designator or pin table is given.
- **Not read:** price and stock of the nPM1304 EK at any seller (Digi-Key and Nordic answered curl with HTTP 403; Mouser and Farnell gave no reply; see the log). The B1 price of US$64.35 was for the nPM1300 EK and is not carried over. The EK user guide `ug_npm1304_ek` (`https://docs.nordicsemi.com/bundle/ug_npm1304_ek/...`, HTTP 403 browser check, `design/bench/sources/nordic_ug_npm1304_ek_a.html`): battery connector pinout, header labels, VDDIO and pull-ups on the EK are therefore not read (plan section 9, points 1 and 2).
- Chip pins and balls the plan uses: `design/ecad/ring/npm1304-balls.csv` (VBAT D1 D2, VOUT1 B6, VOUT2 C6, LSIN1 B4, LSIN2 B5, LSOUT1 A4, LSOUT2 A5, SDA E5, SCL E3, GPIO0 D6, VDDIO E4).
- Outputs of the buck converters on the family: 1.0 to 3.3 V (Zephyr overlay `limits are set to min/max allowed values`, 1,000,000 to 3,300,000 uV) [F]; this is why the bench sets VOUT2 to 3.3 V (plan D1).
- Used in B1 and not used in B2: the nPM1300 EK (NPM1300-EK, US$64.35 [B1]).

## 4. Screen (ring: Tailor Pixels TOH095XVT-01, `design/bom.csv` line 10)

- **The ring's panel cannot run on the bench today.** It needs the vendor's start-up code for the SH8501A (open item 12.1), a panel supply of +4.6 V and -2.2 V (the ring's U4, SGM38046), and a 15-contact 0.3 mm-pitch tail connector (Hirose FH35C-15S-0.3SHW(50), bom.csv line 11) [B1]. ## 5. Storage and level shifting (ring: U3 CSNP32GCR01-BOW, bom.csv line 6; U10 SN74AXC4T774RSVR, bom.csv line 7)

- **Adafruit MicroSD card breakout board+, product ID 254** (stand-in; microSD card not included) [F, `https://www.adafruit.com/product/254`, saved `design/bench/sources/adafruit_254.txt`, read 2026-11-11 23:31 UTC]: price US$7.50 (quantity 1), in stock; onboard 5 V to 3 V regulator, 150 mA; 3 V level shifting with a proper level-shifting chip; 0.1 inch header supplied unattached; pins GND, 5V, CLK, DO, DI, CS named in its wiring sentence. Pin labels on the board (A1 to A8, B1 to B8, VA, VB, OE, GND) are not shown in the page text. Used for SPI lines only.
- **The ring's SD NAND, CS Semiconductor CSNP32GCR01-BOW (LGA-8, 8.0 x 6.2 mm)** [B1, S]: LCSC listing with 2.7 to 3.6 V and an SD interface; SPI-mode pin table in `design/datasheets/slim2_cs-sdnand-20230403.pdf` p4 to p6. A breakout for it: not found [B1, S].
