## 4. Deviations
From the brief of the lead:
1. Media commands (ruling 4, "media commands"): the screens do not call `rip_media_command`. design/firmware.md 7.6 says the Media control mode keeps its keyboard-style keys; the glue already sends them to the active device through ring_control in a session. Calling the iPhone's remote commands too would send every action twice to an iPhone. The Media screen shows the track title and state from the iPhone part.
2. Ruling 5, "SCR_RECORDING ... the waveform of the accepted design may be a simple drawn line set": done as a simple drawn line set, not live (said in section 3).
3. Bar d, "the frame buffer": the simulated chip has no panel, so on the chip the screens draw on the memory display (a RAM frame buffer), the same as on native_sim. The memory display is also the display of the development kit build until the panel driver exists.
4. The notification list and detail are not in design/firmware.md 3.3 or the joystick table of 2.2.
